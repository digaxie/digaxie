## ⚡ About Me

I focus on pragmatic systems software, network protocol instrumentation, and surgical application optimization. My open-source work centers on solving concrete performance bottlenecks, eliminating client-side bloat, and restoring control over local software environments.

- 🌐 **Network & DPI Engineering:** Developed [**CleanNet**](https://github.com/digaxie/CleanNet), a lightweight user-mode DPI bypass proxy that fragments TLS ClientHello packets to defeat ISP-level SNI inspection without requiring root certificates, kernel drivers, or administrative privileges.
- 🛠️ **Desktop Architecture & Patching:** Engineered native ad-blockers and UI optimizers for [**CurseForge**](https://github.com/digaxie/curseforge-adblocker) and [**Blitz.gg**](https://github.com/digaxie/blitz-adblocker), reverse-engineering Electron bundled archives (`app.asar`), resolving multi-monitor layout coordinate bugs, neutralizing ad telemetry loops, and synchronizing binary integrity hashes.
- ⚡ **Game Engine & Runtime Performance:** Authored bytecode-level NeoForge Mixin companions ([**Dragon Mounts Remastered Lag Fix**](https://github.com/digaxie/dragon-mounts-remastered-lag-fix)) to decouple heavy dynamic datapack generation from main-thread player-join ticks, eliminating server freezes.
- 🖥️ **Modern Client Tools & Linux Systems:** Built native **WinUI 3 / .NET 8** modpack distribution pipelines ([**modpack-updater**](https://github.com/digaxie/modpack-updater)) with delta synchronization, alongside user-space **XKB** keymap latency patches ([**instant-capslock-fix**](https://github.com/digaxie/instant-capslock-fix)) for KDE Plasma Wayland sessions.
