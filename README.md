## 💡 How I Build

- **Speed over bloat**: Eliminate unnecessary overhead, memory leaks, and polling loops.
- **Respect the viewport**: Expand compressed layouts and remove intrusive ads to maximize usable space.
- **Direct & surgical**: Prefer targeted patches and transparent scripts that users can easily inspect and revert.
- **1-Click UX**: Provide automated `.bat` / scripts so anyone can benefit without complex terminal commands.
