## About

I like building focused, useful software: tools that make a system feel sharper, interfaces that turn messy information into something readable, and small fixes for annoyances that should not have survived this long.

Right now my public work leans into Linux/Wayland fixes, map-oriented interfaces, networking experiments, and utility apps.
